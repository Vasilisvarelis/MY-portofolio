# Βασίλειος Βαρέλης — Portfolio

Προσωπικό portfolio site (HTML/CSS/JS, χωρίς build step), έτοιμο για **GitHub Pages**.

## Δομή

```
index.html        # Περιεχόμενο της σελίδας
style.css         # Εμφάνιση (dark/light ανάλογα με τη συσκευή, responsive)
script.js         # Μενού κινητού & animations
assets/           # Φωτογραφία προφίλ, favicon
```

## Ενεργοποίηση στο GitHub Pages

1. Κάνε merge το branch στο `main`.
2. Στο repository: **Settings → Pages**.
3. Στο **Source** επίλεξε `Deploy from a branch`, branch `main`, φάκελο `/ (root)` και πάτα **Save**.
4. Σε 1–2 λεπτά το site θα είναι διαθέσιμο στο
   `https://vasilisvarelis.github.io/my-portofolio/`.

## Τοπική προβολή

Άνοιξε απλά το `index.html` στον browser, ή τρέξε:

```bash
python3 -m http.server 8000
```

## Επεξεργασία

Όλο το κείμενο βρίσκεται στο `index.html`. Εκεί αλλάζεις ή προσθέτεις εμπειρίες, δεξιότητες
ή projects. Για νέα φωτογραφία, αντικατέστησε το `assets/profile.jpg`.
